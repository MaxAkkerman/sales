# Старт проекта: продажи сливочного масла М-Групп

## Зачем этот проект

Нужен рабочий контур продаж: понять рынок РФ, выбрать, кому и как продавать промышленное сливочное масло, собрать базу потенциальных клиентов и дать менеджеру простой инструмент учёта контактов и комментариев.

Исходные данные — коммерческое предложение в `коммерческое.txt`.

## Что продаём (из КП)

| Параметр | Значение |
|---|---|
| Продукт | Сливочное масло промышленного качества, ГОСТ |
| Жирность | 82,5% и 72,5% |
| Фасовка | 20 кг (B2B, не розница в пачках) |

Ключевой вывод для стратегии: это **оптовый B2B-продукт для переработки и перепродажи**, не FMCG-пачка в ритейле. Линия только запущена, постоянных покупателей нет — продажи с нуля. Приоритет клиентам, которые берут **сразу бочки/блоки 20 кг**.

## Зафиксированные решения

| Тема | Решение |
|---|---|
| Цена и партия | Всегда по запросу. В стратегии не ставим публичный прайс, учим собирать жирность / объём / регион и считать индивидуально. |
| География | РФ целиком. Ближнее зарубежье — если логистика выгодна и нет сложных юридических барьеров (сертификация, таможня, валюта). |
| Текущие продажи | Постоянных клиентов нет, только разовые. Продуктового предпочтения 72,5 vs 82,5 ещё нет — оба SKU в оффере. |
| Сегменты | Смотрим все. Приоритет A — те, кто закупает промышленную фасовку 20 кг как есть (производство, опт, фасовщики). Розница/мелкий HoReCa ниже. |
| База 1-го этапа | ~150 компаний. Обязательно стараемся найти телефон и email. ИНН, адрес, сайт, ЛПР — если есть. Пустые поля не выдумываем. |
| Источники базы | Итерация 2 — только открытый интернет. Поиск в закрытых базах (Контур, SPARK и аналоги) — отдельная поздняя итерация, если подключат доступ. |
| Приложение | Один пользователь, деплой на облачный сервер. React + API + БД + Docker. Язык UI: русский. |
| Авторизация | Простая, дефолт: логин `maxAkerman`, пароль `maxAkerman`. |
| БД | PostgreSQL. |
| Деплой сети | HTTPS и домен пока не нужны — достаточно `IP:порт`. |
| CRM-фичи сейчас | Только таблица клиентов + контакты + комментарии + статусы. Задачи и напоминания — нет. |
| Письма | Отдельная страница «Шаблоны писем» с заглушкой. Реализация в следующих итерациях. |
| Формулировки | Юридических ограничений нет. В текстах опираемся на **ГОСТ** (подтверждено). |
| Private label | Можно обещать при объёме **от 5–10 т/мес**. Честный знак на монолит 20 кг включён. |
| Смесь базы | Смещена в сторону опта — нужно быстро загрузить линию. Разовых покупателей в базу не кладём (списка нет). |
| Мин. отгрузка | 200–600 кг по Югу своим бортом — ок. |

## Итерации

### Итерация 1 — Рынок РФ и стратегия продаж

Цель: документ, по которому можно идти в продажи без «продаём всем».

Шаги:

1. Карта рынка сливочного масла в РФ
   - объём рынка, динамика, импорт/экспорт, сезонность (праздники, лето/зима)
   - структура спроса: промышленная переработка vs HoReCa vs ритейл vs экспорт
   - ГОСТ vs ТУ, жирность 72,5 / 82,5, требования к сырью и документам (ветсвидетельства, декларации, протоколы)
   - конкуренты: крупные комбинаты, региональные заводы, импорт, «серый» опт
   - ценообразование: логика «по запросу», влияние логистики из Адыгеи, минимальные партии как предмет переговоров
   - ближнее зарубежье: где просто (ЕАЭС) vs где дорого по документам
2. Сегментация клиентов (все в скоупе, приоритет у тех, кто берёт 20 кг)
   - производители кондитерки, мороженого, хлебобулочных, полуфабрикатов
   - молочные комбинаты / фасовщики (в т.ч. private label)
   - оптовые продовольственные компании и дистрибьюторы
   - федеральные и региональные сети (если есть интерес к фасовке 20 кг / СТМ)
   - HoReCa-дистрибьюторы и крупные кейтеринги
   - экспортёры / приграничная торговля (при наличии)
3. Стратегия продаж по каждому сегменту
   - ценность предложения (ГОСТ, лаборатория, стабильность объёма, логистика, СТМ)
   - типичный ЛПР и цикл сделки
   - аргументы, возражения, минимальный объём, условия оплаты
   - канал входа: холодный контакт, тендер, выставка, рекомендация
4. Операционные нюансы
   - документы партии, сертификация, маркировка, сроки годности, температурный режим
   - география: радиус выгодной доставки из Адыгеи vs удалённые регионы
   - мощность 150 т/мес как ограничение воронки (нельзя обещать всем всё)
   - риски: сезон молока, качество сырья, дебиторка, демпинг крупных игроков
5. Итог итерации 1
   - приоритетные сегменты (A/B/C)
   - ICP (идеальный клиент) и anti-ICP
   - playbook первого касания + что спрашивать в заявке (жирность, объём, регион)

Артефакт: `docs/01-market-and-sales-strategy.md` (16.10.2026, на проверке).

### Итерация 2 — База потенциальных клиентов

Цель: список компаний по сегментам из итерации 1, пригодный для обзвона/рассылки.

Шаги:

1. Источники (открытые)
   - сайты компаний, каталоги производителей (кондитерка, мороженое, хлеб)
   - 2ГИС / Яндекс Карты / справочники юрлиц
   - закупочные площадки, тендеры, госзакупки (если релевантно)
   - отраслевые ассоциации, выставки (Продэкспо и аналоги)
   - открытые реестры и публикации
   - закрытые базы (Контур, SPARK и т.п.) на этой итерации **не используем** — см. итерацию 4
2. Карточка клиента (минимум)
   - сегмент, компания, ИНН (если находится), регион/город
   - контакт: телефон и email в приоритете; сайт, ИНН, адрес, ФИО/должность — если находятся
   - оценка потенциала (объём, приоритет A/B/C)
   - источник записи и дата сбора
   - пустые поля не заполняем заглушками
3. Качество, не количество
   - ~150 записей на первый этап
   - упор на тех, кому нужна фасовка 20 кг
   - дедупликация, пометка «нужна проверка контакта»
4. Формат выдачи
   - структурированный JSON (и при необходимости CSV) под импорт в приложение
   - схема карточки = поля таблицы в итерации 3

Артефакт: `data/leads.json` и `data/leads.csv` (16.10.2026, ~150 карточек, упор на опт).

### Итерация 3 — React-приложение для работы с базой

Цель: внутренний инструмент менеджера, не публичный лендинг.

Состав фич (итерация 3):

- страница «Клиенты»: таблица (сегмент, компания, регион, контакты, приоритет, статус)
- фильтры и поиск
- статусы воронки: новый / в работе / квалификация / переговоры / отказ / клиент
- комментарии к строке (история касаний)
- добавление / редактирование клиента
- импорт базы из итерации 2
- страница «Шаблоны писем»: заглушка (создание/загрузка шаблона — следующие итерации)
- логин (один пользователь)

Не делаем сейчас: задачи, напоминания, календарь, роли, мультипользователи.

Технический контур:

- фронт: Vite + React + TypeScript, UI на русском
- бэк: простой API + PostgreSQL
- авторизация: дефолтные `maxAkerman` / `maxAkerman`
- упаковка: Docker Compose (app + db), чтобы залить на облачный сервер

Артефакт: `app/` — Docker Compose (React + API + PostgreSQL), README по запуску.

### Итерация 4 (позже) — Поиск в закрытых базах

Цель: обогатить и расширить базу за счёт платных/закрытых справочников, когда появится доступ.

Возможный скоуп (не делаем сейчас, только закладываем):

- Контур.Фокус / Контур.Компас, SPARK, «Список-Орг», отраслевые платные базы
- дозаполнение карточек: ИНН, руководители, финансы, связанные юрлица, актуальные телефоны
- поиск новых компаний по ОКВЭД / региону / выручке под сегменты из итерации 1
- дедупликация с уже собранными ~150 лидами
- в приложении: действие «обогатить карточку» или отдельный поиск — решим, когда будет API/логин

Зависимости: подписка и допустимый способ использования (ручной кабинет vs API). Без доступа итерация не стартует.

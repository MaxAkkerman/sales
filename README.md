# М-Групп — продажи сливочного масла

Кабинет для работы с базой потенциальных клиентов: таблица, статусы, комментарии, аналитика рынка.

## Запуск

```bash
docker compose up -d --build
```

Или из `app/`: `docker compose up -d --build`.

Открыть http://IP:80 или http://127.0.0.1:8080

- пароль: `maxAkerman`

## Документы

- `START.md` — план итераций
- `docs/01-market-and-sales-strategy.md` — рынок РФ и стратегия продаж
- `data/leads.json` — база ~150 компаний
- `коммерческое.txt` — коммерческое предложение
